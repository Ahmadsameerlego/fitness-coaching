# ADAM RAHMAN / PERFORMANCE COACH — Bilingual Fitness Personal Brand Website

A world-class, premium bilingual (Arabic + English) personal brand web application for **Adam Rahman (آدم رحمن — مدرب الأداء والتطوير البدني)**. Designed for elite online fitness coaches, transformation experts, personal trainers, and high-audience fitness influencers.

---

## 🌟 Key Features

- **Arabic-First Default (`lang="ar" dir="rtl"`)**:
  - Primary design language is Arabic with authentic Egyptian & Modern Standard Arabic marketing copy.
- **Dynamic Bilingual Language Engine (`AR | EN`)**:
  - Seamless language switcher in navbar with zero page reloads.
  - Persists preference in `localStorage`.
- **Typography & Aesthetics**:
  - Google Font **Cairo** for Arabic headlines & body.
  - **Syne** and **Plus Jakarta Sans** for English.
  - Dark luxury visual system (`#070709` charcoal/obsidian background, electric lime `#d4ff00` accents).
- **Interactive Multi-Step Booking Engine**:
  - 3-Step consultation application wizard (Goal $\rightarrow$ Format $\rightarrow$ Form Details) with real-time validation and instant success confirmation state.
- **Transformations Gallery**:
  - Category filter tabs (All, Fat Loss, Muscle Gain, Recomposition) with before/after metrics overlays and interactive popup detail modal.
- **Pure SVG Social Media Icons**:
  - Vector SVG icons for Instagram, YouTube, TikTok, Facebook, and WhatsApp.
- **Intelligent WhatsApp Integration**:
  - Floating bottom-right action button with pulse animation and pre-filled message target.

## 🚀 Quick Start

Simply open `index.html` in any web browser, or launch a local static server:

```bash
npx serve .
```

Or view at: `http://localhost:8080/`
