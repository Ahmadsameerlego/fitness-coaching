# BASSEM SOLIMAN / FOOTBALL PERFORMANCE COACH — Personal Brand Website

A world-class, premium bilingual (Arabic + English) personal brand web application for **Bassem Soliman (باسم سليمان — مدرب أداء وتطوير بدني لكرة القدم)**. Designed for elite football performance coaches, speed & agility trainers, strength & conditioning specialists, and athletic player development experts.

---

## 🌟 Key Features

- **Football Niche Positioning**:
  - Specialized focus on speed & agility, first-step acceleration, 90-minute match stamina, explosive strength, and injury resilience.
- **Arabic-First Default (`lang="ar" dir="rtl"`)**:
  - Primary design language is Arabic with authentic football training terminology.
- **Dynamic Bilingual Language Engine (`AR | EN`)**:
  - Seamless language switcher in navbar with zero page reloads.
  - Persists preference in `localStorage`.
- **Typography & Aesthetics**:
  - Google Font **Cairo** for Arabic headlines & body.
  - **Syne** and **Plus Jakarta Sans** for English.
  - Dark luxury visual system (`#070709` charcoal/obsidian background, electric lime `#d4ff00` accents).
- **Interactive Multi-Step Football Booking Engine**:
  - 3-Step consultation wizard (Goal $\rightarrow$ Training Format $\rightarrow$ Player Details: Name, Phone, Age, Pitch Position, Playing Level) with real-time validation and instant success confirmation state.
- **Player Progress Gallery**:
  - Category filter tabs (All, Speed & Acceleration, Strength & Power, Match Stamina) with before/after metrics overlays and interactive popup detail modal.
- **Pure SVG Social Media Icons**:
  - Vector SVG icons for Instagram, YouTube, TikTok, Facebook, and WhatsApp.
- **Intelligent WhatsApp Integration**:
  - Floating bottom-right action button with pulse animation and pre-filled message target.

## 🚀 Quick Start

Simply open `index.html` in any web browser, or launch a local static server:

```bash
npx serve .
```

Or view at: `http://localhost:8080/`
